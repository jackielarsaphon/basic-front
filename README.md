# To-Do List (การบ้านสัปดาห์นี้ #2)

เว็บไซต์หน้าเดียวสำหรับจดงานที่ต้องทำ เขียนด้วย HTML + CSS + JavaScript ล้วน ๆ ไม่ต้องติดตั้งอะไรเพิ่ม

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงสร้างหน้าเว็บ (หัวข้อ, ช่องเพิ่มงาน, รายการงาน) |
| `style.css` | ตกแต่งหน้าตา (การ์ด, ปุ่ม, รายการ, รองรับจอมือถือ) |
| `script.js` | ทำงานเบื้องหลัง (เพิ่มงาน / ลบงาน / จำงานไว้ในเครื่อง) |

## ฟังก์ชันตามโจทย์

1. **แสดงรายการงานทั้งหมด** — แสดงเป็นลิสต์พร้อมไอคอน และมีตัวนับจำนวนงานด้านล่าง
2. **เพิ่มรายการงานใหม่** — พิมพ์ในช่อง "เพิ่มงานใหม่" แล้วกดปุ่ม "เพิ่ม" หรือกด Enter (ถ้าไม่พิมพ์อะไรจะเตือน)
3. **ลบงาน** — กดปุ่ม `Delete` ท้ายรายการนั้น

เพิ่มเติม: งานที่เพิ่มจะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ ปิดแล้วเปิดใหม่ก็ยังอยู่

## ทดสอบบนเครื่องตัวเอง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์เล็ก ๆ

```bash
python -m http.server 5599
```

แล้วเปิด http://localhost:5599

## อัปขึ้นโฮสต์ (เพื่อส่งลิงก์)

อัปโหลดทั้ง 3 ไฟล์ (`index.html`, `style.css`, `script.js`) ไว้ที่ระดับบนสุดของโปรเจกต์
ห้ามเปลี่ยนชื่อ `index.html` เพราะเป็นไฟล์แรกที่โฮสต์จะเปิดให้อัตโนมัติ

**อย่าลืมทดสอบ**: เปิดลิงก์ในโหมดไม่ระบุตัวตน (Incognito) หรือส่งให้เพื่อนที่ไม่ได้ล็อกอินลองเปิดดู
ว่าเข้าได้จริงก่อนส่งงาน
